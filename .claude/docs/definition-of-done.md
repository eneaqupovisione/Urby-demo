# Definition of Done

Una modifica è finita quando:
- [ ] fa ciò che l'utente ha chiesto, niente di più;
- [ ] il design esistente è invariato, salvo richiesta esplicita (revisione di `ux-ui-designer`);
- [ ] funziona a 390, 768 e 1440px di larghezza, senza scroll orizzontale;
- [ ] rispetta `prefers-reduced-motion`;
- [ ] i testi seguono `voice-and-copy.md` (revisione di `copywriter` se cambia il copy);
- [ ] input, link, dipendenze e configurazione rivisti da `security-expert` se toccati;
- [ ] test aggiunti o aggiornati da `test-engineer`;
- [ ] `npm run check` passa (lint, test, build);
- [ ] il riepilogo all'utente dice cosa è cambiato, come è stato verificato e cosa resta aperto.
